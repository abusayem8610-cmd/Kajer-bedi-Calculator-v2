# 🧮 Kajer Bedi Edition

A premium scientific calculator inspired by the **CASIO fx-991ES PLUS (2nd Edition)**, featuring a beautiful custom design and an adorable animated cat companion.

## ✨ Features

- Advanced scientific calculator functionality
- CASIO fx-991ES PLUS-inspired interface
- Beautiful custom pink and rose-gold design
- Animated interactive cat companion
- Smooth animations and responsive interface
- Android APK support
- Lightweight and easy to use

## Interactive Enhancements

- The cat reacts to actual input, successful calculations, errors, and expression complexity.
- The Info popup provides the Facebook, Instagram, and WhatsApp contact links.
- Original synthesized key sounds can be muted and remembered on the device.
- Holding the LEFT or RIGHT pad direction repeats cursor movement until release.

## Development

Run `npm run dev` to start the local development server and `npm run build` to create the single-file production build.

## 📱 Installation

1. Download the latest APK from the **Releases** section.
2. Open the downloaded APK on your Android device.
3. Allow installation from unknown sources if prompted.
4. Install and enjoy!
